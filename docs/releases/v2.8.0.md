# codex-usage v2.8.0

GPT-6.2 Sol 和 GPT-6.2 Astra 现已纳入历史和新增会话的费用估算。仪表盘可以分别筛选常规、Fast 和 Ultrafast。

| 模型 | 普通输入 | 缓存命中 | 缓存写入（30 分钟） | 输出 |
|---|---:|---:|---:|---:|
| [GPT-6.2 Sol](https://developers.openai.com/api/docs/models/gpt-6.2-sol) | $2.00 | $0.10 | $2.50 | $10.00 |
| [GPT-6.2 Astra](https://developers.openai.com/api/docs/models/gpt-6.2-astra) | $8.00 | $0.40 | $10.00 | $40.00 |

以上为 2026-11-19 核对的 Standard 短上下文 API 价格，按每百万 Token 计。费用按当前目录估算，Token 保留日志原值。两款模型的 Fast 均按订阅内含额度的 2× 折算，Ultrafast 按 6× 折算。购买 credits、API 和企业 PAYG 有各自的费率。[OpenAI 速度倍率](https://learn.chatgpt.com/docs/pricing)

- **历史账目自动更新。** 从 v2.7.3 升级时，会从旧账本中已保存的明确速度记录识别 Ultrafast，无需重新扫描全部历史。未知或冲突的模式仍保留原判断。曾为这两个正式模型或其日期快照填写的临时定价会由内置价格接替。
- **可复核的速度拆分。** 总览、会话、费用和事件导出支持按速度查看。现有 API 的 `modes.fast` 保留加速合计，新增 `modes.ultrafast` 展示其中的 Ultrafast 用量。`mode=fast_only` 与 `mode=ultrafast` 可分别筛选两档。[统计及接口说明](https://github.com/zJay26/codex-usage/blob/v2.8.0/docs/fast-mode-accounting.md)
- **与官方分析配合。** README 增加了账号额度、团队分析和本机项目审计的使用场景对照。[中文说明](https://github.com/zJay26/codex-usage/blob/v2.8.0/README.md#与-codex-官方用量分析怎么配合)

---

GPT-6.2 Sol and GPT-6.2 Astra now have built-in prices for new and historical sessions. The table above lists Standard short-context USD rates per million tokens, including 30-minute cache writes.

- Filter regular, Fast and Ultrafast independently. Both 6.2 models use the Codex included-usage factors of 2× for Fast and 6× for Ultrafast. Raw token counts are preserved.
- Upgrading from v2.7.3 recovers explicitly recorded Ultrafast turns in place. Estimates are recalculated at query time. Temporary pricing overrides for the two official IDs and their dated snapshots give way to the bundled rates.
- The API retains the inclusive accelerated total and exposes the Ultrafast subset in token and cost reports. JSON and CSV exports preserve the recorded tier. The README compares local project and subagent attribution with OpenAI’s account and workspace analytics.
